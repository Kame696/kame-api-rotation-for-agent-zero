# Dependencies for `tests/test_a0_compat.py` — the LIVE harness that imports a real
# Agent Zero checkout and applies KAME's real patches to it.
#
#     pip install -r tests/requirements.txt
#
# You do NOT need this for `tools/a0_upgrade_check.py --latest` or for the
# fingerprint stage (`--skip-tests`): those parse A0's source with `ast` and run in
# a bare Python.
#
# Why this file exists: A0's own `requirements.txt` is ~60 packages and pulls
# torch/faiss/playwright/unstructured. The harness only needs A0 to *import*, which
# is this much smaller closure. Rediscovering it by chasing ModuleNotFoundError one
# at a time costs ~10 pip round-trips. Don't do that again.
#
# Last verified: 2026-08-09, Python 3.14.5 on Windows, against A0 v1.14 / v1.20 /
# v2.1 / v2.4 / v2.7 / v2.8.
#
# `pip install --dry-run -r tests/requirements.txt` must resolve cleanly. It did
# not before 1.0.9 (exact pins on langchain-core + text-splitters 1.x were
# mutually unsolvable). From a clean environment this file now resolves to
# langchain-core 0.3.86 / langchain-text-splitters 0.3.11; the six A0 versions
# above were driven on the equivalent 0.3.49 / 1.1.2 pair.
