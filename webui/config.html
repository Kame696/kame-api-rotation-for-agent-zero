KAME — API Rotation

Multi-key rotation with smart quarantine and an eternal carousel. The engine is intentionally opinionated — these are the only knobs.

Logging

How much KAME writes to the Docker log; the rotation algorithm is the same at every level. normal shows the pool count only when degraded, silent keeps KAME out of the log entirely, and verbose adds heartbeat, timing, pool snapshot and a session summary.

fingerprint is a hash like k3f9a1 — not your real key, so the secret never reaches the log. full writes the whole key; use only for local debugging.

Limits

How long to rest a key after a daily-quota or account / out-of-credit limit (any provider). Overrides a misleadingly short retry hint and caps the adaptive backoff. Per-minute limits are unaffected. Default 3600 (1h); range 1–86400.
