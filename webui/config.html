KAME — API Rotation

Multi-key rotation with smart quarantine and an eternal carousel. The engine is intentionally opinionated — these are the only knobs.

Logging

How much KAME writes to the Docker log. normal shows the pool count only when degraded. verbose+errors also dumps the raw error body so you can verify KAME's classification is correct.

fingerprint is a hash like k3f9a1 — not your real key, so the secret never reaches the log.

Limits

How long to rest a key after a daily-quota or account / out-of-credit limit. KAME probes the key again after this interval — Google's own retryDelay is ignored for daily quotas since it is often wrong. Default 3600 (1h).

Key Pool Status

Live in-memory state. Only anonymized fingerprints are shown — never your real keys. Status resets automatically on container restart.
