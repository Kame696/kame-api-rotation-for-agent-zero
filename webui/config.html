KAME — API Rotation

Multi-key rotation, anti-dogpile / anti-thundering-herd, Trust the Connection (no artificial timeouts), smart quarantine, eternal carousel. Engine settings are intentionally minimal — the plugin is opinionated about how it rotates and how it survives failures.

Observability (v0.5.7.4)

Adds short key id, microsecond-level selection latency, pool snapshot (e.g. pool 14/15 healthy), and a cascade summary to every call log line. Pulse warnings explicitly say Local wait (no API calls) and announce when the next key recovers. Pure observability — no algorithm change and no extra API traffic. Default OFF. Recommended ON when you suspect KAME is the bottleneck or while tuning the key pool.
